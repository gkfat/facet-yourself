# bazi-pattern-analysis Specification

## Purpose
TBD - 八字的格局取格依據（透干）、仇神與閒神、季節氣候分析（簡化調候模型）及其固定內容與呈現。

## Requirements

### Requirement: 格局的取格依據
系統 SHALL 在既有命格（月令本氣的十神）之外，輸出月令藏干是否透出在年、月、時的天干（透干）及取格依據。系統 MUST 只呈現事實與依據，MUST NOT 判定成格或破格、MUST NOT 評價格局高低。

#### Scenario: 本氣透干
- **WHEN** 月令本氣的天干同時出現在其他柱的天干
- **THEN** 輸出「月令本氣透出」與透出的柱位，命格仍以月令本氣為準

#### Scenario: 未透干
- **WHEN** 月令藏干都沒有出現在其他天干
- **THEN** 輸出「月令藏干未透出」，不附好壞評語

#### Scenario: 不輸出成敗
- **WHEN** 回應命盤
- **THEN** 不含「成格」「破格」「格局高低」之類的欄位或文字

### Requirement: 仇神與閒神
系統 SHALL 在用神、喜神、忌神之外輸出仇神與閒神（以十神類別表示）：把十神類別換算成相對日主的五行，生忌神者為仇神，其餘不在用、喜、忌、仇的類別為閒神。日主強弱為中和而不列喜忌時，MUST NOT 列出仇神與閒神。解讀 MUST 使用「較順手／較吃力」的語氣，MUST NOT 說吉凶。

#### Scenario: 有忌神時
- **WHEN** 判定結果列有忌神
- **THEN** 輸出仇神（生忌神的類別）與閒神（其餘類別），五類之間沒有重複

#### Scenario: 中和
- **WHEN** 幫扶分落在 45 至 54
- **THEN** 不列喜神、用神、忌神、仇神與閒神

### Requirement: 季節氣候分析（簡化調候模型）
系統 SHALL 提供「季節氣候分析」，只處理三個層次：（1）月令的氣候偏向：亥子丑為寒濕偏寒、寅涼平、卯溫平、辰溫濕（皆無偏向）、巳午未熱燥偏熱、申酉戌涼燥偏燥，溫度、濕度與氣候偏向分開輸出，且 MUST NOT 因丑、辰為濕土而額外判定偏濕；（2）調節條件：沿用日主強弱的位置權重（藏干按本氣、中氣、餘氣比例，日主自身天干不計）算出火、水各自的相對力量指標（0 到 100），分級為沒有（0）、弱（1 到 14）、中（15 到 34）、強（35 到 54）、過旺（55 以上），調節條件只有不足（沒有或弱）、適中（中或強）、過旺三種結果，「是否存在」MUST 納入地支藏干；（3）調候狀態：偏寒、偏熱、偏燥、相對平衡，並輸出需求（暖局、降溫、潤燥）。判定規則：偏寒月份火不足為偏寒（需暖局）、火過旺標記暖局過度；偏熱月份水不足為偏熱（需潤燥）、水過旺標記潤濕過度；偏燥月份水不足為偏燥（需潤燥）、水過旺標記潤濕過度；春季預設相對平衡；任何月份在得到相對平衡時，火過旺且水不足為偏熱（需降溫），水過旺且火不足為偏寒（需暖局，不標偏濕）。火水同時存在時，系統 MUST NOT 直接認定已平衡。合與沖 MUST NOT 調整力量分數，只標註火、水受合或受沖。系統 MUST 只呈現事實與需求高低，MUST NOT 指示應補哪個五行或建議改運。報告 MUST 標註「簡化調候模型」，註明思想來源為《窮通寶鑑》、力量分級是產品自訂的量化標準而非其傳統判定門檻，並註明「不同流派可能得到不同結果」。

#### Scenario: 子月火弱水強
- **WHEN** 出生在子月，火的力量為弱、水為強
- **THEN** 暖局條件為不足、潤燥條件為適中，狀態為偏寒，需求為暖局

#### Scenario: 藏干納入存在判斷
- **WHEN** 命盤的天干沒有火，但地支藏干有火
- **THEN** 火的力量大於 0，依權重判斷強弱

#### Scenario: 火水都存在
- **WHEN** 命盤中火與水都存在
- **THEN** 不直接判定為相對平衡，而是依兩者的力量分級判斷

#### Scenario: 水過旺火不足的春季
- **WHEN** 出生在春季，水過旺且火不足
- **THEN** 狀態為偏寒，需求為暖局，不標偏濕

#### Scenario: 合沖只標註
- **WHEN** 命盤中火所在的地支受沖
- **THEN** 火的力量分數不變，影響欄位標註「火受沖」

#### Scenario: 辰月
- **WHEN** 出生在辰月
- **THEN** 溫度為溫、濕度為濕，氣候偏向為無，不判定偏濕

#### Scenario: 不給處方
- **WHEN** 回應命盤與報告
- **THEN** 不含「宜補火」「補水」「改運」等處方用語

### Requirement: 格局與調候的固定內容
系統 SHALL 為透干狀態、仇神、閒神與季節氣候分析各提供事先審核的固定內容，MUST NOT 呼叫 AI，MUST 通過既有措辭檢查（含「可能／傾向」、不含診斷與財務用語）。固定內容尚未發佈時，命盤與 API MUST 照常回應，該項解讀省略。

#### Scenario: 內容尚未發佈
- **WHEN** 某筆新增的固定內容尚未匯入
- **THEN** API 仍回傳命盤，該項解讀不顯示，不回 404

#### Scenario: 措辭檢查
- **WHEN** 匯入的內容含診斷用語或預測財運的詞
- **THEN** 驗證失敗並指出該筆內容
