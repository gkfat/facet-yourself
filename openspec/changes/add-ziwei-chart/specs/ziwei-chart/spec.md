## ADDED Requirements

### Requirement: 排盤規則與版本
系統 SHALL 以純函式依固定規則排出紫微斗數命盤：農曆年月日與閏月旗標 → 命宮、身宮、五行局、命主、身主、紫微星位、十四主星、十二宮、生年四化。規則 MUST 固定為：三合系統、以農曆正月初一換年、閏月以月中分界、晚子時日期不換日、出生時刻沿用當地標準時間（已扣夏令）且不做真太陽時。系統 MUST 以 `ZIWEI_ALGORITHM_VERSION` 標示算法版本，任何算法或四化表的變動 MUST 升版。同一份出生資料與算法版本 MUST 永遠得到同一份命盤，且 MUST NOT 依賴目前時間、裝置時區或外部服務。

#### Scenario: 相同輸入相同輸出
- **WHEN** 以相同出生資料與算法版本計算兩次
- **THEN** 兩次的命盤完全相同

#### Scenario: 四化依年干
- **WHEN** 農曆年的天干為任一十天干
- **THEN** 命盤的生年四化為該干在四化表中的祿、權、科、忌四顆星，且四化以標記附在星曜上，不是額外的星

#### Scenario: 十二時辰
- **WHEN** 出生時間落在任一時辰
- **THEN** 命宮與身宮依農曆月與該時辰的地支推得，十二個時辰皆有測試

### Requirement: 閏月與換年處理
閏月出生時，系統 SHALL 以閏月初一至十五歸原月份、十六日起歸下一個月份，並在命盤 metadata 記錄 `isLeapMonth`、`originalLunarMonth`、`effectiveLunarMonth`。農曆年 MUST 於正月初一換年，與八字以立春換年分開。閏月出生者 MUST 看到「各派算法不同，可能有差異」的提示。

#### Scenario: 閏月上半月
- **WHEN** 出生於閏月的初一至十五
- **THEN** 有效月份為原月份，metadata 標示為閏月

#### Scenario: 閏月下半月
- **WHEN** 出生於閏月的十六日之後
- **THEN** 有效月份為下一個月份

#### Scenario: 立春與正月初一之間
- **WHEN** 出生在立春之後、農曆正月初一之前
- **THEN** 紫微的年干依前一個農曆年，不受八字立春換年影響

### Requirement: 晚子時與時辰交界
晚子時（23:00–24:00）的農曆日 MUST 與當天相同，與八字日柱不換日的行為一致，時支為子。出生時間距時辰交界 15 分鐘內時，系統 MUST 顯示時辰可能偏移的提示。

#### Scenario: 晚子時
- **WHEN** 出生於 23:30
- **THEN** 農曆日沿用當天，時支為子，並顯示晚子時與各派算法不同的提示

#### Scenario: 時辰交界
- **WHEN** 出生時間距時辰交界 10 分鐘
- **THEN** 命盤頁顯示邊界提示

### Requirement: 沒有出生時間不提供紫微
系統 MUST NOT 在缺少出生時間時排盤或推測時辰；MUST 回傳明確的驗證錯誤，前端 MUST 引導使用者補填。

#### Scenario: 缺出生時間
- **WHEN** 請求沒有出生時間
- **THEN** API 回傳驗證錯誤，畫面引導補填出生時間

### Requirement: 輸入驗證與年份範圍
`POST /api/ziwei/calculations` SHALL 以 zod 驗證請求，失敗回傳明確錯誤，並以 response schema 驗證回傳。出生年份超出農曆換算可靠範圍時 MUST 拒絕並提示。

#### Scenario: 非法日期
- **WHEN** 日期不存在或格式錯誤
- **THEN** API 回傳驗證錯誤

#### Scenario: 超出年份範圍
- **WHEN** 出生年份超出支援範圍
- **THEN** API 拒絕並說明支援的年份範圍

### Requirement: 命盤事實與解讀分離
命盤資料 SHALL 保留十二宮的事實：空宮 MUST 保持為空宮（`isEmpty`），MUST NOT 把借來的星曜寫成該宮的星。借對宮星曜 MAY 只作為解讀層資訊，並 MUST 明確標示為借星。身宮 MUST 只記錄所在宮位、該宮主星與和命宮的關係，MUST NOT 作為第十三宮或獨立星曜配置。

#### Scenario: 命宮空宮
- **WHEN** 命宮沒有主星
- **THEN** 命盤顯示命宮為空宮，解讀層另行標示借自對宮的星曜

#### Scenario: 命宮與身宮同宮
- **WHEN** 身宮與命宮落在同一宮
- **THEN** 命盤只有一個宮位資料，身宮欄位指向該宮並標示與命宮同宮

### Requirement: 簡化版範圍的說明
命盤頁 SHALL 說明第一版僅呈現十四主星、生年四化、五行局、命主與身主，未包含輔星、煞星、星曜亮度與行運，不同排盤系統可能因此呈現不同結果。命盤頁 MUST 標示採用的流派與算法版本，並顯示「象徵性解讀，非科學測量」。

#### Scenario: 顯示命盤
- **WHEN** 使用者開啟紫微命盤頁
- **THEN** 頁面顯示十二宮命盤、簡化版說明、採用規則與免責聲明
